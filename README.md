# Simple React CoinGecko

Simple React CoinGecko is a small cryptocurrency dashboard built as a learning project. It provides a practical way to explore React application structure, fetch market data from CoinGecko, and build interactive data visualizations with ECharts.

The project also demonstrates how a Nitro server can provide backend-for-frontend API routes, keeping external API access behind the application server while the React client focuses on the user interface.

## Tech Stack

- **React 19** with **TypeScript** for the frontend
- **Vite** for development and production builds
- **ECharts** for interactive cryptocurrency charts
- **Nitro** for backend-for-frontend API routes
- **Axios** for HTTP requests to CoinGecko
- **React Router** for client-side navigation
- **Tailwind CSS** and reusable UI components for styling
- **Lucide React** for interface icons

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Run linting:

```bash
npm run lint
```
